# TSMM v0.15.0

## Highlights

This release adds an **experimental ODRL binding** so TSMM can treat standards-based policy expressions as a first-class comparison surface without collapsing the meta model into a policy language.

## Added

- `bindings/odrl/tsmm-odrl-binding.json`
- `bindings/odrl/constraints.json`
- `docs/bindings/odrl-binding.md`
- `docs/crosswalks/odrl-crosswalk.md`

## Changed

- README and binding index updated to position ODRL as a bounded policy-expression layer inside the broader TSMM architecture.
- Version advanced to `v0.15.0`.

## Architectural note

ODRL is introduced here as a **policy-expression binding only**. It does not replace TSMM semantics for delegation, assurance, evidence, assessment, lifecycle, or trust effects.
