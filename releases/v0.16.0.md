# TSMM v0.16.0

## Release summary

This release makes TSMM more publication-ready and release-clean. It adds an OASF publication guide for turning TSMM-described systems into assurance-addressable publication artifacts, extends the core implementation path from model and validation through publication, and tightens validation and documentation governance for the release.

## What changed

### Added
- OASF publication guidance for TSMM profiles at `docs/profiles/oasf-publication-guidance.md`
- worked OASF publication profile example at `examples/profiles/oasf-publication-profile.json`
- release-aligned publication references in the README, landing page, and docs index

### Updated
- graph-first workflow expanded from model, bind, validate, compare to publish
- OASF binding and crosswalk docs to include publication minimums and usage guidance
- operational profile to include discoverable publication expectations
- documentation metadata refreshed to align with `v0.16.0`

### Fixed
- schema coverage gap in `validation/test_vectors/valid/tsmm-binding-valid.json` by exercising binding `maturity`
- release references and navigation surfaces updated to point to the current release
