# TSMM v0.20.0 — Cross-Repo Artifact Alignment and Executable Governance Binding

**Release date:** 2026-05-05  
**Status:** Additive harmonization release

## Executive summary

TSMM v0.20.0 establishes a coordinated interoperability layer with `trust-infrastructure-schemas` (TIS). The release preserves TSMM as the semantic model for trust systems while enabling concrete projection into executable artifacts for authority, evidence, evaluation, decision, registry publication, and assurance.

## What changed

- Added a Trust Infrastructure Schemas binding under `bindings/tis/`.
- Added cross-repo alignment docs defining TSMM as the semantic layer and TIS as the executable artifact contract layer.
- Added decision receipt, authority boundary, evidence bundle, registry entry, and assurance-level crosswalks.
- Added a cross-repo executable governance walkthrough and examples.
- Replaced placeholder TSMM schema `$id` values with release-pinned repository URLs.
- Refreshed documentation index, binding index, freshness audit, and README release posture.

## Governance impact

The release makes it easier for implementers to move from model-level architecture to audit-ready artifacts. A trust decision can now be modeled in TSMM and expressed as a TIS decision receipt with policy, authority, evidence, result, revocation, assurance, and effect constraints preserved.

## Migration notes

This release is additive. Existing TSMM examples and bindings remain usable. Implementers that relied on `example.org` schema identifiers should update references to the new release-pinned schema IDs.
