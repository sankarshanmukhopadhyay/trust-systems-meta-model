# TSMM v0.12.0

## Release name

**Agent Classification and Attention Governance**

## Summary

v0.12.0 extends the agentic extension so TSMM can describe not only delegated action, capabilities, contexts, and traces, but also the operating posture of agentic actors and the governance of signal routing before interruption or representation occurs.

This release is shaped by two external inputs: the Taxonomy for Agent Systems and the Self-Sovereign Attention stack. Rather than import either model wholesale, TSMM absorbs the parts that sharpen agent governance without collapsing the core into product-specific abstractions.

## Additions

- added `agentClass` and `controlMode` objects to `schemas/tsmm-agentic-extension.schema.json`
- added `attentionPolicies` to `schemas/tsmm-agentic-extension.schema.json`
- expanded `examples/agentic-ai-extension-instance.json` with an execution agent and an attention-gateway agent
- added `docs/model/agent-role-classification.md`
- added `docs/model/attention-governance.md`
- added `docs/crosswalks/agent-taxonomy-ssa-crosswalk.md`
- refreshed `README.md`, `docs/index.md`, `docs/extensions/index.md`, `docs/extensions/agentic-ai-extension.md`, `docs/roadmap.md`, and `docs/freshness-audit.md`

## Why this matters

TSMM already knew how to model delegated action. v0.12.0 makes it easier to model **what kind of actor is acting**, **under what control posture**, and **how signal admission itself becomes a governed trust decision surface**.

That makes the model more useful for digital twin systems, personal AI assistants, predictive side-cars, and other agent-mediated systems where the question is not only whether an agent may act, but whether it may interrupt, represent, defer, summarize, or reroute demands on a principal’s time and attention.
