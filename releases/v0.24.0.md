# TSMM v0.24.0: Executable Cross-Repository Semantic Governance

TSMM v0.24.0 makes cross-repository semantic authority and projection machine-verifiable. It introduces stable semantic identifiers, a canonical semantic concept registry, a TIS semantic projection contract, repository-local portfolio relationship assertions, compatibility metadata, and validation for semantic and release-version drift.

## Added
- `model/semantic-concepts.json` with stable `urn:tsmm:concept:*` identifiers.
- `schemas/tsmm-semantic-concept-registry.schema.json` and `schemas/semantic-projection.schema.json`.
- `bindings/tis/tsmm-tis-semantic-projection.json`.
- Portfolio relationship and TIS compatibility contracts.
- Semantic projection and version-consistency validators.

## Authority boundary
TSMM continues to own canonical semantics. TIS retains independent authority over schema identifiers, serialization, validation contracts, and releases. Portfolio classification remains outside TSMM.

## Compatibility
This release is additive. It strengthens traceability and validation without changing stable TSMM core instance semantics.
