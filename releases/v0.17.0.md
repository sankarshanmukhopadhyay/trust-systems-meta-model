# TSMM v0.17.0

## Release summary

This release adds an **experimental runtime-governance interpretation layer** to TSMM. The core model remains stable. The new material sharpens how TSMM can describe execution-time trust decisions, trust boundaries, and pre-effect policy admission using the Microsoft Agent Governance Toolkit as an upstream reference point for runtime interception and security-boundary thinking.

## What changed

### Added
- `docs/model/trust-boundary.md` as an experimental supporting abstraction for execution edges
- `docs/patterns/pre-effect-governance-pattern.md` to model decision-time policy admission before an effect occurs
- `docs/crosswalks/agent-governance-toolkit-crosswalk.md` to document the experimental interpretation boundary
- `examples/runtime-governance-pre-effect-instance.json` as a worked TSMM example

### Updated
- README, docs index, landing page, and roadmap for `v0.17.0`
- validation script to include the runtime-governance example
