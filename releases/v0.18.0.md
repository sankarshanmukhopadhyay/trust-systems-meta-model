# TSMM v0.18.0 — Runtime Assurance and Documentation Integrity

## Summary

TSMM v0.18.0 operationalizes runtime assurance by adding machine-readable artifacts for pre-effect governance and auditable decision receipts. The release also refreshes repository documentation metadata so the published model surface is aligned with the current version.

The main shift is from describing runtime governance to making it testable. Authority, delegation, revocation freshness, trust-boundary crossing, policy binding, evidence binding, effect admission, and decision receipts are now represented as explicit artifacts.

## Governance impact

This release strengthens TSMM as executable governance infrastructure. It makes runtime authority evaluation inspectable before effect execution and reviewable after the decision. That supports stronger assurance for delegated agents, trust registries, tool invocation flows, and systems where revocation state must be enforced rather than merely documented.
