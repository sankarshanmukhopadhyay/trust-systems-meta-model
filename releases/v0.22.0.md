# TSMM v0.22.0: Delegation Lineage and Topology

## Summary

This additive release normalizes multi-hop and fan-out delegation as explicit authority-graph patterns. It enables implementations to model not only whether an actor received authority, but whether downstream authority remains traceable, attenuated, current, and legitimate as branches cross domains or converge.

## Added

- `pattern.chained-delegation` and `pattern.fanout-delegation`.
- Canonical failure modes for broken lineage, scope expansion, principal substitution, translation amplification, aggregation amplification, and partial revocation.
- Linear-chain and fan-out implementation examples.
- Implementer guidance and glossary definitions.

## Compatibility

No existing entity, relationship, or delegation pattern is removed. Existing instances remain valid. Implementations should adopt the new patterns when delegation depth exceeds one or when concurrent branches contribute to one effect.

## Assurance evidence

The delegation pattern catalog validates against the updated schema; repository examples and documentation checks remain part of the release gate.
