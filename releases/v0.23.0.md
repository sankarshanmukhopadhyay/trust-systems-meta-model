# TSMM v0.23.0

Promotes TSMM to an internally coherent, evidence-backed Candidate publication posture. The release adds the member-owned status contract, Just The Docs publication, governance and architecture diagrams, repository-wide Mermaid validation, portfolio relationship normalization, and Candidate evidence generation.

## Assurance boundary

Candidate is not certification. Independent interoperability and implementation assurance remain future work.
