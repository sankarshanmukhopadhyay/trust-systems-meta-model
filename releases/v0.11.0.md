# TSMM v0.11.0

## Release name

**Agentic Profile and Binding Completeness**

## Summary

v0.11.0 closes several structural gaps that became visible after v0.10.0 made TSMM publishable as machine-readable infrastructure. It completes the binding catalog for two important areas, adds a cross-cutting conformance profile for agentic deployments, extends the registry schema so the new artifacts can be indexed cleanly, and improves graph rendering for review and assurance use cases.

## Additions

- added machine-readable DCAS binding under `bindings/dcas/`
- added machine-readable Verifiable Trust Communities binding under `bindings/vtc/`
- added `docs/conformance/tsmm-profile-agentic.md`
- extended registry publication schema with `agentic-instance` support
- updated the registry example to publish bindings and agentic instances together
- enhanced `render_tsmm_graph.py` with clustering and profile annotation flags
- refreshed README, bindings index, glossary, implementer guide, docs home, and freshness audit
- added `docs/roadmap.md`

## Why this matters

v0.10.0 established the publication shape. v0.11.0 makes that shape more complete and more operational. The result is a tighter connection between extension work, registry indexing, and conformance guidance for agentic deployments.
