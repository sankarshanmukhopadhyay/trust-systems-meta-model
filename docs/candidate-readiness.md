# Candidate readiness

TSMM is a **Candidate specification** under active validation. Candidate means the model is near feature-complete for its declared scope and is supported by systematic repository validation. It does not assert certification or production-system assurance.

## Evidence gate

Run `make candidate-check`. The gate validates examples, bindings, positive and negative test vectors, YAML models, graph and registry artifacts, documentation, schema coverage, governance declarations, portfolio relationships, Mermaid syntax, and the built documentation site.

## Authority boundary

TSMM owns canonical trust-system semantics and graph contracts. Portable schema serialization remains under TIS authority. Implementations, external protocols, and independent assurance retain their own authority.
