## Drift status

The release gate passed the drift pressure-test corpus. TSMS classifies independently observed state as:

| Disposition | Assurance meaning |
| --- | --- |
| `UNCHANGED` | accepted state is independently evidenced |
| `REVIEW_REQUIRED` | material drift exists; inherited compatibility is withdrawn |
| `UNSUPPORTED` | state is outside the supported component/declaration contract |
| `INDETERMINATE` | authoritative state cannot be obtained or verified |

No `INDETERMINATE` result is treated as PASS.

## Authority boundaries

TSMS coordinates evidence; it does not centralize authority.

- **TSMM** owns canonical trust-system semantics.
- **TIS** owns portable contracts, identifiers, and validation rules.
- **TGA** owns executable governance compositions and implementation patterns.

A gap must be escalated to the repository that owns the relevant authority.

## Limitations and non-claims

This status does not establish external certification, correctness of an adopter implementation, compatibility with unreviewed future state, or a production successor baseline. Green CI is supporting evidence, not by itself the assurance decision.

## Supersession history

`tsms-stack-2026.1 — Cashew-Nut` is the first TSMS stack release. No prior stack release is superseded. Future releases should link their predecessor and preserve historical receipts and evidence rather than rewriting them.
